HDE Studio — 2D Architectural CAD

Standalone Desktop Architectural CAD Software built in Java

Java Desktop • v2.2.63

The Problem & Solution: Commercial CAD software (AutoCAD, Revit) is bloated, cost-prohibitive, and slow for rapid 2D floor plans. Engineered a standalone, lightweight, zero-dependency desktop CAD studio from scratch in Java Swing.

System Architecture & Complexity:

  • Vector Drafting Engine: Implemented a 2D vector coordinate pipeline supporting multi-thickness walls (9" exterior, 6" interior, 4.5" partition) with an endpoint-welding algorithm that joins corner vertices and T-junctions automatically in real time.
  • AutoCAD-Style Polygon Hatch Algorithm: Custom point-in-polygon clipping engine rendering dynamic vector fills (2'x2' vitrified tiles, 45° herringbone, diagonal ceramic, hardwood planks).
  • Section & Elevation Generator: Automatic orthographic projection rays (XLINE / RAY) and structural cross-section generator (A-A') detailing stepped masonry footings, plinth beams, and lintels.
  • High-Resolution Vector Export Engine: Exports technical drawings to ISO sheet formats (A4/A3 up to 8000px resolution) and social media ratios with double contractor title-block borders and CAD pen colors.
  • Distribution & Licensing: Packaged into native Windows standalone executables (.exe installer) via jpackage with cryptographic offline license keys.

Client-Side Document Engineering & AI Media SaaS Platform

WASM • Client-Side AI • Next.js 16

System Architecture & Complexity:
